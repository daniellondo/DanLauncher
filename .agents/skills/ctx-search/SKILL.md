Prefer `ctx_search` when available.

- Scope searches to `project:DanLauncher`.
- Batch related questions.

- Retrieve raw files only after search identifies the relevant location.
- If Context Mode is unavailable, use the runtime's repository search and keep results narrowly scoped.
